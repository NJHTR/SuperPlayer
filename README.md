# 🎵 SeekPlayer - 你的专属音乐空间

![SeekPlayer 界面截图](screenshot.png)

## 🌟 应用简介

SeekPlayer 是一款设计优雅、操作简单的音乐播放器，让你在纯净的听觉体验中享受每一刻的音乐时光。

## ✨ 核心功能

### 沉浸式音乐体验
- 流畅播放你喜爱的所有歌曲
- 支持创建多个个性化播放列表
- 智能记忆上次播放位置

### 视觉享受
- 实时跳动的音乐频谱可视化
- 多种精心设计的主题配色
- 日间/夜间模式自由切换

### 贴心设计
- 简洁直观的操作界面
- 音量精细调节
- 播放进度自由控制

## ❓ 使用帮助

1. **如何添加音乐？**  
   点击"上传音乐"按钮或直接将音频文件拖入窗口

2. **如何切换主题？**  
   点击右上角的调色板图标选择你喜欢的颜色

3. **如何创建播放列表？**  
   在右侧播放列表区域点击"+"按钮
